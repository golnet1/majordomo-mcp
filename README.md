# majordomo-mcp
MCP-MajorDoMo-Xiaozhi


🏠 MCP Bridge для MajorDoMo — Умный дом с ИИ

Лицензия Python Платформа


MCP Bridge — это полноценная система управления умным домом на базе MajorDoMo, интегрированная с ИИ-агентом xiaozhi через протокол MCP (Model Context Protocol).

Поддерживает управление голосом, веб-интерфейс, расписание и сценарии.


📌 Обзор

Этот проект обеспечивает полный мост между MajorDoMo (открытой системой автоматизации дома) и ИИ-агентом с использованием протокола MCP. Включает:

✅ MCP-сервер — подключает ИИ к MajorDoMo

✅ Веб-панель — создание и редактирование устройств, настройка

✅ Планировщик — автоматизация по расписанию

✅ Работает на Raspberry Pi, Linux-серверах.

🚀 Быстрый старт

📌 Требования

Сервер Linux или Raspberry Pi

Python 3.10+

📌 Кроссплатформенность (Windows)

Модуль содержит поддержку Windows (экспериментальная ветка):

- определение ОС и путей к виртуальному окружению (`Scripts\python.exe` / `Scripts\pip.exe`, `where python`);
- поиск/остановка процесса `mcp_pipe.py` через PowerShell `Get-CimInstance` (`wmic` не используется — он устарел и удалён в новых сборках Windows), резервный вариант через `wmic`;
- запуск `mcp_pipe.py` через PowerShell `Start-Process -WindowStyle Hidden` с передачей `MCP_ENDPOINT`;
- `install()`/`uninstall()` учитывают Windows (`rmdir /S /Q`).

Важно: автозапуск и перезапуск моста выполняет `scripts/cycle_mcp.php`
(цикл MajorDoMo). На Windows убедитесь, что цикл реально запускается; при
отсутствии — запускайте `mcp_pipe.py` вручную или через Планировщик задач.
На Linux поведение прежнее, Windows-ветки не выполняются.

📌 Колонки и комнаты

Колонка (XiaoZhi) добавляется как устройство типа «Колонка (XiaoZhi)» с указанием
MAC-адреса и комнаты. Если в промпте роли на xiaozhi.me есть системная переменная
`{{device_id}}` (MAC устройства), модуль по нему определяет, из какой комнаты пришла
команда, и выполняет её в этой комнате — название комнаты можно не произносить
(достаточно «включи свет»). Если колонка не добавлена как устройство, модуль работает
как раньше — без привязки, с уточнением комнаты.
